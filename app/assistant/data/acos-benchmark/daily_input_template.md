# Daily Input Template — ACOS Morning Brief v0.1

One message, structured (fill only what's real; leave blanks — the agent will flag `חסר`):

```
DATE: 2026-07-04

TASKS (today's list):
1. ...
2. ...

BUILD ITEMS (with evidence, if any):
- <item> — evidence: <exact quote / "signed" / "meeting on calendar 2026-07-08" / none>

PROSPECTS (one block each):
- name/clinic: ___
  last message (verbatim + date): "..."   (leave empty if none)
  history (1 line, facts only): ___

CALENDAR TODAY/THIS WEEK: <meetings, or "none">
```

Rule: paste **verbatim** prospect utterances. No paraphrase — the agent classifies stage from the exact quote.
