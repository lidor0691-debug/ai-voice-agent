# Expected Daily Output Format — ACOS Morning Brief v0.1

Action-first, ≤1 screen:

```
🔴 TOP TASK (A): <one line> — first action now: <exact step/message>

TASKS:
- <task> — REVENUE_PROXIMITY A/B/C  (C-tasks: kept "מוצדק כי…" or DELETE)
- ...
BUILD: <item> — EVIDENCE_CLASS PAID/COMMITTED/VERBAL/IMAGINED → allowed scope
WIP: build=<thread>  sell=<thread>  (open a 4th only after closing one: <which>)

PROSPECTS:
- <name> — SALES_STAGE <X> (quote: "…") — NEXT_COMMITMENT: <dated ask>
  → ready-to-send: «<Hebrew message>»

חסר: <anything missing that blocks a call>
```

If no A-task: leads with `אזהרה: אפס משימות הכנסה היום` + one הצעה (cold/new channel, no invented contacts).
